Slate Sorter

Reads scanned slates, checks each Subject ID against its barcode, and files every slate into its school code folder, then into a folder for its session type (YBK, ESS, POP, GRAD or OTHER). Everything stays on this computer.

Have lots of separate slate files?

Select them all in File Explorer, right-click, and choose Send to → Compressed (zipped) folder. Then choose that ZIP here. PDF, JPG and PNG files inside it are read; anything else is listed and skipped.

Which session is this?

Slates with a missing or mismatched Subject ID go into the Flagged folder for a person to check. Slates where only the session type is unclear stay in their school folder, and you can pick the session type when the scan finishes. A results spreadsheet is saved alongside the folders.

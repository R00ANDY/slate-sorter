Slate Sorter

Reads scanned slates, checks each Subject ID against its barcode, and files every slate into its school code folder, named with its session type (YBK, ESS, POP, GRAD or OTHER) and the student's name. Everything stays on this computer.

Have lots of separate slate files?

Select them all in File Explorer, right-click, and choose Send to → Compressed (zipped) folder. Then choose that ZIP here. PDF, JPG and PNG files inside it are read; anything else is listed and skipped.

2

Choose where to save

Pick the same folder every time. Inside it each school gets a folder, with a folder per graduation year (for example MIASR/2027). Retake and In-School slates go into Retake and In School folders inside the year folder. Non-Contracted and Previous Seniors slates go to 0_Non_Contracted, and slates whose school can't be read go to 0_Flagged. A running log of every slate sorted into this folder is kept in it too.

Which session is this?

Slates with a missing or mismatched Subject ID, or no readable graduation year, go into a 0_Flagged folder inside their school's year folder (or higher up when the year or school can't be read) for a person to check. Students already sorted before go to 0_Duplicate, except Retake and In-School slates. Slates where only the session type is unclear stay in their school folder, and you can pick the session type when the scan finishes. A results spreadsheet is saved alongside the folders.
